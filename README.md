# Boutique CrossFit Lisieux : stock affiché sur le site

Ce dépôt contient un seul fichier utile, `boutique.json`, mis à jour chaque soir depuis le QG de la box.
La page https://crossfit-lisieux.fr/boutique-crossfit-lisieux le lit pour afficher « En stock » ou « Bientôt de retour » et, pour nos vêtements, le prix.

Il ne contient que ce que la page affiche déjà : pas de quantité, pas de coût, pas de fournisseur.
